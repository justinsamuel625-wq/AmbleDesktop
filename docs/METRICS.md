# Metric registry

All calculated metrics are generated by `amble.analysis.analyze_session` from the persisted raw sample file, never from a separate in-memory summary. A metric row stores its phase, value, unit, classification, quality decision, and failure details.

| Metric | Function / algorithm | Unit | Classification | Assumptions and quality requirement |
|---|---|---|---|---|
| Valid samples | `valid_samples_pct`: valid and confidence-gated rows / all rows × 100 | % | Direct measurement | At least one recorded row; validity semantics depend on tracker |
| Tracking confidence | mean minimum per-eye confidence × 100 | % | Direct measurement | Tracker confidence semantics are backend-specific |
| Sampling rate | inverse median timestamp interval | Hz | Direct measurement | At least two ordered timestamps |
| Dropped frames | gaps in source frame-number sequence / expected span × 100 | % | Estimated | Source increments identifiers once per acquired frame |
| Mean gaze error | mean Euclidean target-to-binocular distance | normalized screen units | Estimated | Calibrated normalized coordinates; ≥60% quality-gated samples |
| RMS gaze error | √mean(dx² + dy²) | normalized screen units | Estimated | Known target; ≥60% quality-gated samples |
| BCEA 68 | `bcea`: 2πk σx σy √(1−ρ²), k=−ln(1−0.68) | normalized screen area | Estimated | Approximately bivariate distribution; ≥30 valid samples |
| Fixation drift | `drift_rate`: distance between robust first/last 10% centroids / elapsed time | normalized units/s | Estimated | Stable target; ≥30 valid samples |
| Left/right fixation RMS | per-eye √mean(dx² + dy²) | normalized screen units | Estimated | Per-eye calibrated coordinates; ≥60% valid |
| Left/right BCEA 68 | per-eye BCEA formula above | normalized screen area | Estimated | ≥30 valid samples |
| Eye asymmetry | absolute difference between per-eye RMS errors | normalized screen units | Estimated | Comparable per-eye calibration; ≥60% valid |
| Vergence proxy | mean(right gaze x − left gaze x) | normalized horizontal difference | Proxy | Comparable per-eye calibration; never presented as a clinical angle; ≥60% valid |
| Pursuit RMSE | target-to-binocular RMS error | normalized screen units | Estimated | Synchronized target events; ≥60% valid |
| Pursuit lag | `pursuit_lag_ms`: full cross-correlation peak | ms | Estimated | Near-uniform sampling and preferably ≥2 target cycles |
| Pursuit gain | `pursuit_gain`: gaze standard deviation / target standard deviation | ratio | Estimated | Smooth non-stationary trajectory; ≥60% valid |

No low-quality metric is coerced to zero. The stored value is null and the UI displays “Insufficient tracking quality.”
